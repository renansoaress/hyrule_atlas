### Breath of the Wild
The Fierce Deity Set is an Armor Set consisting of the Fierce Deity Mask, Fierce Deity Armor, and Fierce Deity Boots. All three pieces can be obtained using the amiibo Rune while scanning the Majora's Mask Link amiibo. Each time the figure is scanned, a Treasure Chest will appear that has a small chance to contain one of the pieces. As the amiibo can only be scanned once per real-world day, a player must collect the Set over three or more real-world days.

The Set can be enhanced by a Great Fairy but cannot be Dyed at the Kochi Dye Shop. When it has been enhanced by two levels, it provides the Charge Atk. Stamina Up Set Bonus when worn with the full Set, while each piece individually provides a single Attack Up effect. It resembles the armor worn by Fierce Deity Link from Majora's Mask.
