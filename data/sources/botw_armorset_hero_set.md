### Breath of the Wild
The Hero Set is an Armor Set consisting of the Cap of the Hero, Tunic of the Hero, and Trousers of the Hero. All three pieces can be obtained using the amiibo Rune while scanning the 30th Anniversary 8-Bit Link amiibo. Each time the figure is scanned, a Treasure Chest will appear that has a small chance to contain one of the pieces. As the amiibo can only be scanned once per real-world day, a player must collect the set over three or more real-world days.

The set can be enhanced by a Great Fairy but cannot be Dyed at the Kochi Dye Shop. When it has been enhanced by two levels, it provides the Master Sword Beam Up Set Bonus when worn with the full set. It resembles Link's outfit from the original The Legend of Zelda.
