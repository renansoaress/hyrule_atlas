### Breath of the Wild
The Hero of Twilight Set is an Armor Set consisting of the Cap of Twilight, Tunic of Twilight, and Trousers of Twilight. All three pieces can be obtained using the amiibo Rune while scanning the Super Smash Bros. Link amiibo or Twilight Princess Link amiibo. Each time the figure is scanned, a Treasure Chest will appear which has a small chance of containing one of the pieces. As the amiibo can only be scanned once per real-world day, the Armor Set must be collected over the course of three or more real-world days.

The Hero of Twilight Set can be enhanced by a Great Fairy but cannot be Dyed at the Kochi Dye Shop. When it has been enhanced by two levels, it provides the Master Sword Beam Up Set Bonus when worn with the full set. It resembles Link's outfit from Twilight Princess.
