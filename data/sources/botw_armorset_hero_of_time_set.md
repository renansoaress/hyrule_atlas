### Breath of the Wild
The Hero of Time Set is an Armor Set consisting of the Cap of Time, Tunic of Time, and Trousers of Time. All three pieces can be obtained using the amiibo Rune while scanning the Ocarina of Time Link Amiibo. Each time the figure is scanned, a Treasure Chest will appear that has a small chance to contain one of the pieces. As the Amiibo can only be scanned once per real-world day, a player must collect the set over three or more real-world days.

The set can be enhanced by a Great Fairy but cannot be Dyed at the Kochi Dye Shop. When it has been enhanced by two levels, it provides the Master Sword Beam Up Set Bonus when worn with the full set. It resembles Link's outfit from Ocarina of Time.
