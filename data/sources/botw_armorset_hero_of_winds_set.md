### Breath of the Wild
The Hero of Winds Set is an Armor Set consisting of the Cap of the Wind, Tunic of the Wind, and Trousers of the Wind. All three pieces can be obtained using the amiibo Rune while scanning the Super Smash Bros. series Toon Link or The Legend of Zelda 30th Anniversary series Toon Link amiibo. Each time the figure is scanned, a Metal Chest will appear that has a small chance of containing one of the pieces. As each amiibo can only be scanned once per real-world day, the set must be collected over two or more real-world days.

The Hero of Winds Set can be enhanced by a Great Fairy but cannot be Dyed at the Kochi Dye Shop. When each piece has been enhanced by two levels, the Master Sword Beam Up Set Bonus takes effect when the full set is worn. It resembles Link's outfit from The Wind Waker.
