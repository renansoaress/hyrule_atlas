## Location and Uses
The Salvager Armor Set is an Armor Set consisting of the Salvager Headwear, Salvager Vest, and Salvager Trousers, added as part of the "[Xenoblade Chronicles 2]" collaboration in Breath of the Wild's Version 1.3.3 update. All three pieces are found throughout Hyrule where red Shooting Stars fall, as part of the "[Xenoblade Chronicles 2]" Side Quest. Each piece provides a level of Swim Speed Up when equipped, with the adoption of the entire Armor Set granting Swim Dash Stamina Up. The Salvager Armor Set cannot be upgraded by a Great Fairy nor Dyed at the Kochi Dye Shop. Once found, Granté sells parts of the Armor Set for 50 Rupees apiece.
