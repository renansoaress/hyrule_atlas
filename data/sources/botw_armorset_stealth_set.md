### Breath of the Wild
The Stealth Set is an Armor set consisting of the Stealth Mask, Stealth Chest Guard, and Stealth Tights. Each piece of the Stealth Set can be purchased at "Enchanted," an Armor shop in Kakariko Village.

The Sheikah designed this armor for stealth purposes, so each piece of the Stealth Set provides the Stealth Up effect. Wearing the entire set while every piece is upgraded at least twice provides the Night Speed Up set bonus, which increases Link's movement speed at night. However, this armor has lower defense when compared to other armor sets.

Unlike regular Sheikah clothing, which cannot be purchased by folk of other races, the Stealth Set is available for all to purchase, such as Link or Bugut.BotW

## Trivia
* Concept artwork of the Stealth Set from Breath of the Wild shows that it originally resembled the everyday clothes worn by members of the Sheikah tribe. However, the Stealth Set was later redesigned to resemble the clothes worn by Sheikah warriors instead.
