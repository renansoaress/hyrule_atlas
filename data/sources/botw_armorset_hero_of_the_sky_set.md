### Breath of the Wild
The Hero of the Sky Set is an Armor Set consisting of the Cap of the Sky, Tunic of the Sky, and Trousers of the Sky. All three pieces can be obtained using the amiibo Rune while scanning the Skyward Sword Link amiibo. Each time the figure is scanned, a Treasure Chest will appear that has a small chance to contain one of the pieces. As the amiibo can only be scanned once per real-world day, a player must collect the set over three or more real-world days.

The set can be enhanced by a Great Fairy but cannot be Dyed at the Kochi Dye Shop. When it has been enhanced by two levels, it provides the Master Sword Beam Up Set Bonus when worn with the full set. It resembles Link's outfit from Skyward Sword.
